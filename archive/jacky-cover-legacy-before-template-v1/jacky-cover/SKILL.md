# Jacky Cover

这是 `$oil-cover` 的运行时品牌补丁，复用其内容分析、证据与 prompt 骨架；本 Skill 规定 Jacky 品牌、人像、参考使用和编辑方式，不另建生成流水线。

## 加载与执行边界

1. 定位并完整读取当前 `$oil-cover/SKILL.md`；缺失时停止。读取其用户配置：人物版使用 `agent-native`；若为 `script`，说明差异，由用户选择临时切换或无人物 Oil Cover，不静默改配置。
2. 完整读取 Oil Cover 的 `references/agent-native-flow.md`、`references/cover-rules.md`，查看 `docs/showcase/gallery.png`；读取宿主 `imagegen` Skill 和本 Skill 的 [品牌与排版字段](references/visual-system.md)。同一任务已读内容不重复加载，除非文件变化。
3. 优先级：当前明确要求 > 此前已确认且未撤销的局部 > 本次指定参考的用途 > Jacky 品牌默认 > Oil Cover 默认。新要求只覆盖涉及部分；“头部方向自然”只确认方向，不等于整张封面通过。
4. 本补丁覆盖 Oil Cover 的无人物/后置合成、截图强制提炼和裁切、默认字形及人物空间关系条款；用户指定完整面板时不强制重组或裁边。其余内容归因、证据分析与字段骨架继续沿用。
5. 画面主体使用内置 ImageGen。当前已获用户明确授权的主标题方式为：生图生成不含主标题的底图，再用真实阿里巴巴普惠体 Bold 字体文件本地排主标题；主标题改字、字号和颜色时只重新排字，不重生人物。手写补充可随画面生成。此授权仅覆盖排字及保持纵横比的画布适配，不扩大为本地换脸、修肤或拼接人像。其他明确要求整图生图的任务仍按用户选择；不得把生成字形称为已使用真实字体。生图与编辑都不保证人物像素级保真；用户要求原照像素不变时另行说明直接合成方式。
6. 只制作用户需要的画幅，未限定时遵循 Oil Cover 默认。先做主画幅再扩展；未指定主画幅时先做 3:4。用户正在纠正人物或布局时先解决该画幅，避免扩散缺陷；正常任务自检通过即可继续，不额外设置确认关卡，不擅自减少最终交付画幅。

## 素材与图片用途

通读原稿；检查源文件旁及已知对应项目的输出与验收目录，只查本次相关项目。记录 `素材检查`：查了哪里、找到什么、选或不选的理由，不因用户只给稿件路径就认定没有实物成果。

- `real-screen`：存在对应真实截图、视频帧、课件页或成品预览。实际查看后选本期证据，传入工具。Logo 和历史封面不算本期真实证据。另在 plan 说明使用方式：
  - **完整面板**：用户说“用这张做面板”“保留完整截图”时，保留内部布局、文案及元素关系；可以整体缩放、移动和处理边缘，不拆出元素重排到背景，不删除内部信息以满足外层去字规则。原有窗口外框属于面板本身；描边沿现有边缘处理，不套第二层容器。裁去截图外部无关留白不得损伤面板。
  - **提炼重组**：用户要求去噪或提炼，或未指定完整保留且截图确有干扰时，按 Oil Cover 选核心证据并说明保留与删除内容。不能将用户已排好的课件默认当成待拆散 UI。
- `transcript-derived`：确实只有原稿。提取可视化成果、关系或场景，明确为编辑型示意，不伪造真实 UI、数据、Logo 或运行成功状态；不必总画流程图。

一个主要视觉中心可以是一组连贯成果，不等于只有空卡或巨大数字。逐张标注图片角色：编辑目标、内容证据、风格/构图参考、Logo、原始身份照片。同一张图包含多种信息时说明只采用哪些部分；参考封面的人物不能充当 Jacky 身份源。

## 标题、参考与内容分工

- **主标**：用户指定封面文案时保留文字、标点与组合方式。需要从文章提炼短标题时优先用 DBS 的封面标题模块；先读实际模块，确认它处理封面短标题，不能仅凭目录名含 title 就认定已调用。模块不可用时明确说明，按 Oil Cover 内容分析提炼，不冒称 DBS 结果，不自动安装依赖。主标只讲一个结论、动作或痛点，不擅自缩短型号。
- **副标**：一句明显较小的补充，讲方法、依据、价值或条件，不重复主标。用户不要或仅重复时可省略，写明理由；不能因排版拥挤静默删掉用户副标。
- **面板**：展示本期成果或关系。提炼/示意模式只保留理解图像所需的短标签，不再造第三组大标题；完整面板模式保留原内容。忽略文字后仍应辨认本期具体成果，不能只剩通用窗口。
- **归因**：谁完成工作，谁是主产品；承载工具留在证据中，Logo 不挤断主标题。
- **读参考**：先提取标题起点、主副标层级、面板/人物位置、留白与遮挡关系，再选字形和材质。按用户说明采用参考的指定特征；不要只抄颜色字体却忽略空间关系，也不无依据复制参考人物动作、物件或文案。

标题字形、撕纸、品牌色、优先构图和安全区统一见 [品牌与排版字段](references/visual-system.md)。先确定主副标原文与语义断行。主标题采用本地真实字体时，只把标题预留区交给生图，提示词明确禁止生成主标；手写补充保留准确文案。字体文件核对family/style并记录路径、hash、字号、坐标和边界；不能为等宽拉伸字形或硬拆词。

## 原照人像与系列感

默认采用 [品牌与排版字段](references/visual-system.md) 中的「纸蓝剪纸互动」方向；只有明确指定旧版或延续已选旧稿时才用旧版上置标题。芽仔身份参考与动作约束也见该文件。

身份取自两张清晰的 Jacky 原始照片。优先检查 `assets/jacky-reference-front.jpg` 与 `assets/jacky-reference-side.jpg`，选择符合所需朝向的一张为主、另一张辅助；确认是原照而非带生成水印的衍生图。文件名不证明真实性，缺原照时说明缺口，不拿旧生成脸补位。

- 原照同时提供身份与自然头颈肩结构，保持脸型、五官、短发、年龄感及下颌—颈根—肩线—领口的连续关系。换衣不意味着改身体比例；不自行写缩颈百分比、抬肩像素或单独缩放头部。用户已认可的头部方向继续保留。
- 默认自然、有精神、从容。不为制造差异强加歪头、举掌、惊讶、卖萌或销售姿态；自然重复姿态与无手势都允许。
- 默认真人在上方视觉区与芽仔、隐喻物件形成轻量互动，下方留两行标题；旧版右下上半身落底构图仅用于延续旧稿。可随用户参考调整。明确胸像/上半身裁切，默认不露裤腰、胯、腿。人物不截断、不悬空，不遮主标、Logo 和主证据；交叠只覆盖非关键面板表面，不强行交叠。
- 默认让真人通过一个轻量动作参与隐喻，芽仔操作关键关系；动作由本期内容决定，不固定按按钮。检查手与前臂的自然结构、前后关系及内容可见性；若手势不能自然成立，可用视线或身体朝向建立互动，不凭一句描述认定合格。
- 查看用户认可成图和最近封面（最多4张），记 `最近封面对照` 与 `连续封面差异`，比较层级、人物自然度和证据形态。不设“至少改变N项”，不为系列差异牺牲质量。

## 首稿与局部编辑

在现有 `cover_plan.md` 简短记录当前的**本轮要改、必须保留、参考角色、尚未确认**，没有则写无；不把历次互相冲突的修补指令累加进去。

- **首稿**：按本轮内容、参考和品牌生成完整画面。
- **文字修改**：已采用本地排字时，复用未带主标题的原始底图与同一字体文件，重跑排版；保留底图、透明标题层、排版脚本和参数记录。不要从已带字成品擦字或重新生成整个人物。
- **局部编辑**：先查看选定的可用候选，作为 edit target；保留原始身份照作为身份源。写明只改什么、保持什么，未变字段描述应保留的现状。修人物不顺带换标题面板，修错字不重新设计布局。旧候选只用于编辑底图或已认可姿态/构图，不能递归替代原照。
- **整体重做**：仅在用户明确要求、整体结构失败或没有可用底图时选择，说明理由，仍保留未撤销的要求。

编辑输出也要对照全部保留项，不能因目标缺陷改善就忽略其他漂移。工具 edit 不是像素锁定保证。

出现人物白斑、脸型纵横比例变化、五官漂移，或用户反馈“不像本人”时，该候选的人物验收立即不通过。不要继续把这张失真人像或其后续版本当作下一轮编辑底图，即使同时附了原照也不能视为已经恢复身份。回到两张原始身份照；需要重建时，用文字记录已确认构图，只传原照和必要非人像素材，切断失真生成脸的引用链。将原照与新图的脸部等比例裁切并排查看，不通过拉伸脸部或任意缩放头颈修正。分别记录身份、皮肤和版式是否通过；文字或边缘修好了不能替代人物验收。若原照重建仍不像，停止叠改并说明缺口；需要原照像素不变时，提出直接合成路线，按用户授权执行。

## Prompt 与生成前检查

按 Oil Cover `cover-rules.md` 提示词骨架顺序填写，将无人物与 `Local portrait composite guard` 换为 `Portrait integration guard`，在 `Avoid` 前放 `Jacky brand patch`。编辑也沿用骨架，只描述当前目标状态，不另叠一套构图。完整面板在 `Screenshot distillation plan` 明写保留整体内容、不拆分；不能保留上游禁止完整截图的互斥句。

人物具体位置与几何只在 Composition 一处写清。品牌字段是可调整基底，不是逐字背诵门禁。参考按实际编号写角色；优先保障编辑目标、原照、用户指定证据与参考，Oil gallery 事前查看但不必每轮上传。按当前工具能力安排数量，不能声称未上传图已传入；有 Logo 时先保障实际需要的参考，输入不足以满足要求时先说明缺口，不盲目重试。

保存 `analysis.md`、`cover_plan.md` 和当前画幅 `.prompt.md`：

- analysis：素材检查、证据模式、主主题、主产品、承载界面、辅助品牌、一眼主语、主证据、辅助证据、可牺牲信息、标题提炼依据、最近封面对照、目标人物动作、身份锚点来源（原始照片）。
- plan：标题断行、副标题（正文或省略理由）、内容分工、面板可视化与使用方式、强调词、构图、屏幕裁切、人物裁切、人物层级、人物空间关系、参考输入及角色、连续封面差异、本轮要改、必须保留、尚未确认。

将 `JACKY_COVER_SKILL_DIR` 设为当前 Skill 的真实目录；以下参数用实际文件替换。`--refs` 只列本次实际上传素材，按需追加编辑目标、内容/风格参考或 Logo；顺序须与 prompt 一致。

```bash
python3 "$JACKY_COVER_SKILL_DIR/scripts/validate_run.py" \
  --prompt "<当前画幅.prompt.md>" --analysis "<analysis.md>" \
  --plan "<cover_plan.md>" --aspect "<3x4|4x3|16x9>" \
  --refs "<原照1>" "<原照2>" \
  --identity-refs "<原照1>" "<原照2>"
# real-screen 另加 --evidence-refs "<已列在refs的主证据>"
# 有Logo时另加 --logo-refs "<已列在refs的Logo>"
# --max-refs 默认5；仅按已核实的宿主上限调整，不为绕过超限而增大
```

脚本只验证结构、文件与声明角色的一致性，不能验证原照真实性、实际工具是否收到图片、人物自然度或审美。核对实际调用与记录一致；报错修好再生图，结构通过不等于视觉通过。

## 验收与停止条件

打开原图、文字和头颈肩局部，再看等比例信息流缩略图（3:4 约270×360，横版保持横向比例）。对照原照、证据、用户参考和本轮保留项：

1. 主副标逐字准确，特别检查人名、形近字、型号、数字与标点；看不清记未验证。字形完整，行间不因描边粘连；缩略图中先读主标再读副标。
2. 标题及装饰外沿在安全区内。面板主体可辨，完整面板未拆件、删关键内容或重复套框；人物没有遮挡关键证据。
3. 人像身份、年龄、肤色和头颈肩自然；无白斑、皮肤上的描边/纸纹，脸与身体无拼接感。衣着、朝向、裁切符合当前计划，不能只检查“像本人”。
4. 品牌色、撕纸或其他选定材质与参考布局成立，截图和 Logo 语义原色保留。编辑目标改善且其余保留项未发生不接受的变化。

文字/归因错误、要求遗漏、人物或截图失真、关键遮挡必须处理。每个失败画幅最多自动修订一次，按问题选 edit 或整体重做；再次失败保留候选并明确缺口，不宣称完成、不重复相同请求。用户明确继续时按新范围执行，已确认部分不清空；同一问题反复出现要调整依据或说明能力边界，不只是追加形容词。比例建议的轻微偏差不作为无限重生理由。

记录路径、尺寸、参考图、原图/局部/缩略图检查、保留项对照与未解决问题。`manifest.final.json` 分开记录自检结论与 `user_acceptance`；用户只认可局部就写清局部，其余仍未确认。存在明确缺陷不得写 pass；自检通过也不冒称用户认可。保留旧候选和对应 prompt，不覆盖用户未要求更换的版本。
