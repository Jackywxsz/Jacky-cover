# 固定纸蓝互动模板

当前只有 `interaction-profile.json` 指定的一套默认模板；底部1/3标题区与蒙版保持固定，标题按 v8 规则左对齐铺满。继续复用v4纸底原字节，蒙版按v7参数独立生成。旧版规则已归档，不在本文保留第二组互斥默认。

## 固定视觉

- 背景以v4固定PNG为唯一视觉源：暖纸上部与中央、右上方较宽的柔和清蓝过渡、左侧中下部的清蓝晕染。来自用户指定封面去除人物/贴纸/文字/黑遮罩后的背景还原；隐藏区域属补全，不宣称逐像素恢复。不得重新解释为左右蓝边框、纯白中心、小角落点缀或整块蓝紫底。固定PNG只缩放到模板尺寸一次，后续重复使用，不让生图重画。
- 已确认的暖纸底原版保存在assets/covers/masters/paper-blue-paper-master-v3.png，hash见配置；当前v4在同一设计基础上微调蓝色，减少紫感。原版是留存母版，不自动回退，不再重新发明纸底。
- 背景与遮罩分开。v7采用连续smoothstep曲线：45%高度以上黑alpha为0，从45%至89%高度柔和增加到94%，之后保持94%。相较v6，上方图像区遮罩更轻；深色集中在标题背后并自然向上渐隐，不另画黑色矩形、不加上方对称黑遮罩。以配置与实际蒙版为准。
- 层序：固定背景→透明互动前景（下缘平滑收口）→黑蒙版→小字和主标题。半身人物延伸到标题后，末端不能在主标题上方露出硬截线。不能将旧压平图再蒙一次黑；合成器不接受任意替换背景。
- 真人身份来自原照和用户认可的姿势图（见 SKILL.md 素材规则），不把生成的前景或封面再上传修改。皮肤清晰自然，无粉笔白斑、脏纹、压扁脸型。真人自然照片外沿，无描边。芽仔和道具保留纸片/贴纸的薄切边、手绘轮廓和浅接触阴影；局部材质不能污染真人皮肤或整张纸底。禁止光滑玩具、白棚家电、厚重块状3D阴影。
- 标题区固定为底部1/3；1080×1440时为y960–1440。标题两行，严格保持用户指定断行，不能擅自挪词；排版规则见下方“标题排版步骤”。真实阿里巴巴普惠体Bold，白字与一个橙色语义重点；按字体真实advance宽度排字，不能拉伸、加假粗或由模型近似。小字使用清楚自然的手写字体，优先放上部清晰留白并保持显眼；不是第三个标题。

## 固定与自适应边界

以下是后续默认执行契约，不是每次重新征求偏好的选项。唯一数值源为 `interaction-profile.json`，本文说明用途；模板资产与配置不因单张文案而修改。

| 固定项 | 执行方式 |
| --- | --- |
| 画幅与纸蓝底 | 复用配置指定的1080×1440、v4固定底图及其hash；保留暖纸质感和不对称清蓝晕染，不重画、不变紫、不做左右蓝框。 |
| 主标题区 | 固定底部1/3；左右安全边距、底部安全线、行间距按配置；两行左对齐，较长行铺满，左右边距一致。 |
| 黑色蒙版 | 独立一层，严格使用v7曲线：上部45%无遮挡，45%–89%以smoothstep连续变深，到94%黑后保持。禁止矩形标题底板、重复叠黑、把旧0/20/60/80分段建议重新当成当前参数。 |
| 字体与颜色 | 真实阿里巴巴普惠体Bold；主标题白色、指定强调词橙色。小字使用配置中的真实手写字体，不由模型生成近似字。 |
| 前景安全区 | 按配置等比放置；人物偏右、语义主场景优先上移，人物下缘延伸进标题暗部柔和收口。不可拉伸人脸或裁断肢体来适配。 |

每张可变的是文案、指定断行、逐行字号、强调词、小字内容与实际留白位置，以及服务内容的人物/芽仔动作。身份、芽仔比例和纸片材质仍严格遵守固定视觉与验收规则。

### 标题排版步骤

1. 先锁定两行文字与强调词。用户明确断行时逐字遵守；未明确时按语义分两行，不为放大字号拆散产品名。
2. v8 默认自动排版（用户 2026-11-07 要求）：第一行是大标题，在左右安全边距内铺满（上限 `max_auto_size`）；第二行是副标题，字号约为第一行的 `subtitle_ratio`（0.62），长度随文字，不强求右对齐；两行左对齐，可见间距 `line_gap`；整块底边在 `bottom`（87.5% 高度），下方留给小红书观看数图标。超出标题区时一起缩小。
3. 只有自动结果明显不合适时才给某行写 `size`；写了的行按指定字号排，超宽直接报错，不拉伸字形。
4. 看全图与手机缩略图：两行左对齐、铺满、紧凑，不压人脸和主场景。
5. 小字优先放上部清晰留白，相对显眼但不抢主标题；避开头脸、手势、内容主体和主标，不固定顶部正中，也不硬性固定在芽仔下方。

只改字号、文字、底图合成或蒙版时复用已接受透明前景，不调用生图。若用户明确要求更换固定模板，才另做版本并保留旧版备份；旧版不自动启用。用户接受单张校样不等于之后所有人物生成都已通过，未来每次新前景仍需独立验收。
