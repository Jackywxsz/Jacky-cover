# 固定纸蓝互动模板

当前只有 `interaction-profile.json` 指定的一套默认模板；用户已接受v7校样；底部1/3标题区、两行位置及蒙版保持固定，字号随文案适配。继续复用v4纸底原字节，蒙版按v7参数独立生成。旧版规则已归档，不在本文保留第二组互斥默认。

## 固定视觉

- 背景以v4固定PNG为唯一视觉源：暖纸上部与中央、右上方较宽的柔和清蓝过渡、左侧中下部的清蓝晕染。来自用户指定封面去除人物/贴纸/文字/黑遮罩后的背景还原；隐藏区域属补全，不宣称逐像素恢复。不得重新解释为左右蓝边框、纯白中心、小角落点缀或整块蓝紫底。固定PNG只缩放到模板尺寸一次，后续重复使用，不让生图重画。
- 已确认的暖纸底原版保存在assets/covers/masters/paper-blue-paper-master-v3.png，hash见配置；当前v4在同一设计基础上微调蓝色，减少紫感。原版是留存母版，不自动回退，不再重新发明纸底。
- 背景与遮罩分开。v7采用连续smoothstep曲线：45%高度以上黑alpha为0，从45%至89%高度柔和增加到94%，之后保持94%。相较v6，上方图像区遮罩更轻；深色集中在标题背后并自然向上渐隐，不另画黑色矩形、不加上方对称黑遮罩。以配置与实际蒙版为准。
- 层序：固定背景→透明互动前景（下缘平滑收口）→黑蒙版→小字和主标题。半身人物延伸到标题后，末端不能在主标题上方露出硬截线。不能将旧压平图再蒙一次黑；合成器不接受任意替换背景。
- 真人每轮从两张原照全新生成，不输入旧生成肖像，不在生成脸上反复编辑。皮肤清晰自然，无粉笔白斑、脏纹、压扁脸型。真人自然照片外沿，无描边。芽仔和道具保留纸片/贴纸的薄切边、手绘轮廓和浅接触阴影；局部材质不能污染真人皮肤或整张纸底。禁止光滑玩具、白棚家电、厚重块状3D阴影。
- 标题区固定为底部1/3；1080×1440时为y960–1440。标题两行，严格保持用户指定断行；两行可见间距须通过配置下限检查，随字号自然变化，避免过散；标题行宽适度收窄而不拉伸字形，支持逐行字号，短第一行可单独放大，不能擅自挪词。真实阿里巴巴普惠体Bold，白字与一个橙色语义重点；按字体真实advance宽度排字，不能拉伸、加假粗或由模型近似。小字使用清楚自然的手写字体，优先放上部清晰留白并保持显眼；不是第三个标题。

## 固定与自适应边界

以下是后续默认执行契约，不是每次重新征求偏好的选项。唯一数值源为 `interaction-profile.json`，本文说明用途；模板资产与配置不因单张文案而修改。

| 固定项 | 执行方式 |
| --- | --- |
| 画幅与纸蓝底 | 复用配置指定的1080×1440、v4固定底图及其hash；保留暖纸质感和不对称清蓝晕染，不重画、不变紫、不做左右蓝框。 |
| 主标题区 | 固定底部1/3；两行起始位置、左右安全边距、底部安全线按配置。标题区占1/3不代表每行文字必须占满整幅宽度或高度。 |
| 黑色蒙版 | 独立一层，严格使用v7曲线：上部45%无遮挡，45%–89%以smoothstep连续变深，到94%黑后保持。禁止矩形标题底板、重复叠黑、把旧0/20/60/80分段建议重新当成当前参数。 |
| 字体与颜色 | 真实阿里巴巴普惠体Bold；主标题白色、指定强调词橙色。小字使用配置中的真实手写字体，不由模型生成近似字。 |
| 前景安全区 | 按配置等比放置；人物偏右、语义主场景优先上移，人物下缘延伸进标题暗部柔和收口。不可拉伸人脸或裁断肢体来适配。 |

每张可变的是文案、指定断行、逐行字号、强调词、小字内容与实际留白位置，以及服务内容的人物/芽仔动作。身份、芽仔比例和纸片材质仍严格遵守固定视觉与验收规则。

### 标题排版步骤

1. 先锁定两行文字与强调词。用户明确断行时逐字遵守；未明确时按语义分两行，不为放大字号拆散产品名。
2. 默认共同字号由合成器按真实字体宽度适配；需要层级时，在 `text.json` 的每行 `size` 显式设置字号。短上行可适度放大，长上行正常排，不强制上行大于下行。合成器不会自动判断“短行应放大”，执行者须根据文案选择并检查。
3. 不靠增加字距或横向拉伸去撑满行宽；保持左右呼吸与自然字形。字号必须同时通过行宽、底边和行间距校验。不能为一行字改模板坐标或压缩另一行字形。
4. 看全图与手机缩略图：两行有清楚层级、不过散、不拥挤。当前已接受案例为“如何发挥 / Grok Bot最强实力”，200/110px、可见间距45px；这只是复现该案例的记录，不是通用字号或通用行距。
5. 小字优先放上部清晰留白，相对显眼但不抢主标题；避开头脸、手势、内容主体和主标，不固定顶部正中，也不硬性固定在芽仔下方。

只改字号、文字、底图合成或蒙版时复用已接受透明前景，不调用生图。若用户明确要求更换固定模板，才另做版本并保留旧版备份；旧版不自动启用。用户接受单张校样不等于之后所有人物生成都已通过，未来每次新前景仍需独立验收。

## 内容与动作

新前景先按[导演式构图](scene-direction.md)决定场景瞬间、第一落点、主次体量、前后遮挡与角色任务；再读动作库。上方纸片场景需成为能独立传意的画面，不能仅在人物旁排列相关物件。

先确定一句核心判断、必须可识别的内容主体和一个关系，再设计人物与芽仔的动作和作用结果。具体产品/角色/团队参考优先于通用隐喻，不能用通用图标或芽仔替代原题主体。真人参与其中但不抢走语义中心。固定身份/媒介不等于固定姿势/道具；同一人物可自然前倾递交、展开、托举并操作、双侧比较、统筹协作或观看；先按内容设计关系，再读pose-library.md选动作，不能把指一下作为默认。一个主场景，至多三个辅助物件，遮字后仍能理解主要关系。

## 必须分开验收

1. **数值/图层**：母版hash与配置一致；真透明前景而非白底；白色衣服/纸片内部不透明；独立纯黑alpha蒙版；实际渐变曲线与采样值；最终尺寸；真实字体；文字/前景边界；只改文字时主体不变化。
2. **人物**：实际上传清单没有旧生成肖像；对照原始照片的脸型、五官、年龄与皮肤；两条手臂逐段可追踪；没有缺臂感、多指或错误连接；肩/袖不触边；蒙版没有掩盖结构错误。
3. **芽仔**：身份与原始比例不变，完整躯干、短腿圆靴，腿脚不拉长、躯干不挤没；无五官面罩单侧连续反光；仍是纸片/贴纸媒介；动作与物件有接触和结果；不能变成旁观装饰。
4. **语义**：画面传递原题要点，用户指定对象/产品/群体真实出现在画面且可识别；遮住芽仔仍能认出主要对象，未用通用生产线代替所有主题；没有虚构事实或产品能力。
5. **导演构图**：关键动作、物件状态与可见结果对应主题；第一落点与计划一致，真人与芽仔各有作用，接触和遮挡成立；记录遮字后的可能误读，不能仅因“含有报告／机器人”就判主题准确。
6. **整体**：暖纸主底/右上与左侧蓝晕和固定参考母版一致，人物与主要内容上移、上半部没有无意义的大块空区；人物上部清晰，人物下缘融入标题暗部；小字克制且位置合理；手机缩略图中两行主标与互动关系可读。

任何视觉项不通过就记录具体缺口，不能以脚本pass覆盖人工fail。脚本报告默认是“待视觉审阅”，不会自动宣称完成。
