# 动作参考库（K 系列）

封面里 Jacky 的互动动作就那么几类，每期从这里选一张作为**动作参考**，作为 image 4 上传。它只管身体朝向、手臂和手的位置；脸和身份永远以 front / side 原照（image 1、2）为准。图里的道具（放大镜、手机、电脑）只是示意，提示词里没写就不画。

来源：`experiments/pose-library-v3/`（由原照生成，提示词在 `prompts/`）。以后有更好的动作或参考，生成后经用户认可再追加，编号往后排。

| ID | 动作 | 适合 |
|---|---|---|
| K01 | 单手平托掌心，低头看着掌上 | 托着一个微观世界、看清内部 |
| K02 | 双手前伸悬在胸前，掌心朝下，像在操控下方 | 指挥、编排一个微缩场景 |
| K03 | 前倾，单手把手机推向镜头 | 手机里的工具、App 成果 |
| K04 | 双手端着打开的笔记本朝镜头 | AI 替你干活、成果从屏幕出来 |
| K05 | 侧身，双手指向左上 | 身后窗口、步骤、流程 |
| K06 | 一手平托，另一手食指指着掌心 | 介绍掌上一个小东西、关键机关 |
| K07 | 抱臂，看镜头 | 观点判断，芽仔承担全部操作 |
| K08 | 双手摊掌朝画面左侧展示 | 身侧展板、对比、展示结果 |

挑动作：先定画面，再找手部关系最接近的那张；画面需要的动作库里没有，就选最接近的，在提示词里写清差别（如“不拿放大镜，掌上托着跑道”）。
