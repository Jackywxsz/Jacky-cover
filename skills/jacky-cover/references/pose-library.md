# 动作参考库（K 系列）

封面里 Jacky 的互动动作就那么几类，每期从这里选一张作为 image 4 上传：**人物身体就照这张来**——姿势、手的位置、身体比例和取景（到腰）都不变，场景按他的手势来放。脸以 front / side 原照（image 1、2）核对。图里的道具（放大镜、手机、电脑）只是示意，提示词里没写就不画。

来源：K01–K08 来自 `experiments/pose-library-v3/`，K09 起来自 `experiments/pose-library-v4/`（用户 2026-11-08 选定）；都由原照生成，提示词在各自的 `prompts/`。以后有更好的动作或参考，生成后经用户认可再追加，编号往后排。

| ID | 动作 | 适合 |
|---|---|---|
| K01 | 单手平托掌心，低头看着掌上 | 托着一个微观世界、看清内部 |
| K02 | 双手前伸悬在胸前，掌心朝下，像在操控下方 | 指挥、编排一个微缩场景 |
| K03 | 前倾，单手把手机推向镜头 | 手机里的工具、App 成果 |
| K04 | 双手端着打开的笔记本朝镜头 | AI 替你干活、成果从屏幕出来 |
| K05 | 侧身，双手指向左上 | 身后窗口、步骤、流程（用户觉得两手翘指偏秀气，优先用 K08） |
| K06 | 一手平托，另一手食指指着掌心 | 介绍掌上一个小东西、关键机关 |
| K07 | 抱臂，看镜头 | 观点判断，芽仔承担全部操作 |
| K08 | 双手摊掌朝画面左侧展示 | 身侧展板、对比、展示结果 |
| K09 | 单手平托掌心低头看（无道具，K01 的替代） | 托着一个微观世界 |
| K11 | 单手轻摊掌朝画面左侧，另一手自然下垂 | 身侧的窗口、物件，轻量展示 |
| K13 | 侧身，食指自然指向左上 | 身后窗口里的某一步 |
| K15 | 双手撑在桌面上俯身低头看 | 俯看桌面上的微缩场景 |
| K16 | 一手托下巴思考，看向左上 | 选择、对比、值不值得类观点 |
| K18 | 侧身低头，双手在腰前像往下方放东西（备选） | 搭建、摆放 |

挑动作：先挑动作，再按这张动作的手势设计场景（物件放在他手托或手指的位置）。不临时编新动作；常用动作不够时，另外生成、经用户认可后加进库。
