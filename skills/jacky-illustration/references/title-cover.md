# 封面模式：理解内容，固定品牌骨架

## 标题与隐喻

提炼原文核心判断，让结论或转折成为主标，背景与铺垫成为较小较轻的辅文。保留用户指定原题及其中的限制条件。辅文可轻微倾斜，不能为手写感牺牲可读性；主标一至两行，按语义断行。

芽仔必须执行可见且有意义的动作，角色与物件有接触和结果。一项动作、一个主要物件组，至多三个辅助物件或短标签。不要把文章所有论点都压到封面。少元素与强表达同时成立，不能靠把 IP 缩成小贴纸获得留白。

## 默认小红书固定模板

- 背景：`assets/covers/clean-window-3x4-v1.png`，2160×2880 的固定母版，含干净浅底、淡蓝边缘、白色圆角窗框和三色按钮。直接复用，不生成、不染旧、不累计纸纹。
- 人物：`assets/ip/jacky-portrait-window-v1.png`，同尺寸透明定位图层，内含已确认原照片圆窗。固定位置与大小，不再经过生成模型。
- 芽仔：`assets/ip/yazai-paper-blue-anchor-v1.png` 锁定身份；仅借鉴 `assets/examples/paper-blue/01-scene-metaphor-16x9-v2.png` 的编辑线描与低密度表达，不复制背景、道具或重纹理。
- 输出：1245×1660 PNG；需要保真人物源像素时同时保存 2160×2880 合成母版。内容层放大必须如实注明。

坐标按整个画布归一化，左上角为原点：

| 区域 | 约束 |
|---|---|
| 内容安全区 | x 8%–94%，y 12%–89% |
| 标题 | y 14%–36%，位于内框上方约三分之一；辅文约主标字号的 40%–55% |
| 芽仔与主场景 | 中段约 y 39%–82%；整体高度以内框的 40%–50% 为参考，按场景调节 |
| 人物圆窗 | 原图层固定中心约 x 71.46%、y 72.53%；直径约画布宽度的 35.7% |
| 人物保护区 | x 52%–92%，y 58%–88%，内容层在这里必须完全透明 |

人物上方可以有场景；低于 y58% 的插画集中在左侧，给圆窗留出间隔。主标、场景、人物分别可读，保留明显空白。比例是本模板的布局基准，不能套用到配图或横版封面。

长标题先区分主标与辅文并按语义重排；只有获准才能压缩原题。不能缩小芽仔到难以辨认，不能移动或遮挡固定人物来迁就文字。仍不适配时说明具体冲突并给出缩题建议。

## 生成与合成

1. 从原文生成视觉任务，明确主判断、辅助文字、芽仔动作与避让区。
2. 用内置图像生成工具生成一张与母版同为 3:4 的 **真实透明内容 PNG**，仅含标题、芽仔和必要道具。请求 `transparent_background=true`，不要画窗框、背景、真人、空白圆圈或人物占位符。白色主体必须不透明。
3. 检查全文准确、芽仔身份、动作、真实 alpha、标题位置及人物保护区。生成器可能忽略百分比坐标或在透明空白处留下孤立 alpha 像素；以实际 alpha 边界为准。文字与插画可作为独立透明组件等比缩放、定位，空白处孤立瑕疵用局部确定性清理，不能切掉字、手脚或关键动作。不能把白底 JPEG 或棋盘格图片当透明图，也不能靠反复整图生成调整位置。
4. 使用本地合成工具，按固定底图 → 内容 → 人物顺序合成。人物原层只做像素合成，不用生成式修脸。
5. 检查实际成品和 270×360 缩略图。只修改有问题的层；原底图与原人物资产不动。

运行目录为 Skill 根目录，输入和输出路径由当前项目决定：

```sh
python3 scripts/compose-cover.py --content content.png --output cover.png --master master.png --thumbnail thumbnail.png --report report.json
```

依赖 Python 3 和 Pillow。无外部 API、账户或后台服务。脚本只读取本地素材；任何依赖缺失都明确报告，不静默安装。

`--content` 必填；`--output` 必填且固定输出 1245×1660；`--master`、`--thumbnail`、`--report` 可省略。底图默认使用已打包母版，不提供每次更换底图的开关。

人物可通过 `--portrait path.png --portrait-mode cutout` 指定已确认的透明抠像。它须预先按母版尺寸定位，并全部落在人物保护区内；脚本不抠像、不重绘、不擅自放大。默认 `window` 使用打包圆窗。需要不同人像占位时先获得新模板确认，不能悄悄侵占主内容区。

输入比例不符、内容越界、保护区有非透明像素、人物没有完整透明通道、素材缺失或输出已存在时，脚本报错且不交付成品。重新指定输出版本，不能覆盖输入。透明层失败时仅处理内容层，不退回整张封面生成。

## 保真与验收证据

- 合成母版中人物完全不透明的像素必须与原人物图层一致；边缘 alpha 正常融合。
- 标准版是母版正常缩放，不能宣称发布尺寸与源图像素逐一相同。
- 母版未覆盖的背景应与固定底图一致，不能出现每次生成带来的底纹变化。
- 源内容分辨率写入报告；放大不等于增加真实细节。低清源素材不能仅靠高像素导出判定合格。
- 脚本检查尺寸、透明度、保护区和像素；标题含义、字体观感、IP 露出、清晰度和呼吸感仍须看图验收。不能仅凭脚本通过宣布视觉通过。

## 人物形态与其他平台

圆窗是默认。透明人物抠像仅在用户提供并确认，或明确要求制作且脸部保真已验证时启用；没有抠像资产时不虚构人物，也不把圆形裁图称作抠像。

公众号 2.35:1、X Article 5:2 保持自由构图，默认复用 `assets/ip/jacky-headline-avatar-v1.png` 原透明头像，位于第三视觉层级，不与圆窗重复使用。头像不重绘，不遮挡芽仔的主要动作。用户自带人物素材优先。

- 公众号：1410×600 或 900×383。
- X Article：1500×600。
- 共用母版仅在用户要求时用 1500×600，关键元素位于水平中央 94%；两平台原生版须独立重排。

横版不强裁竖版模板；真人大片或界面证据驱动的封面另用 `$jacky-cover`。

## 该复用什么

复用主次判断、IP 动作、清洁品牌视觉、原照片分层和固定模板。不要复用某个标题、剪刀、Bot、笔记、配角数量、机器绝对路径或临时工具命令。模板确定品牌位置，故事由内容重新决定。
