# Jacky 视觉图解

一个 Skill，两种用途，共用内容理解、Jacky 蓝和芽仔身份。固定品牌骨架，按内容设计表达。

## 选择模式

| 请求 | 模式 | 人物与构图 |
|---|---|---|
| 封面、视频封面、小红书封面 | 封面 | 标题 + 芽仔互动；小红书默认固定干净窗框和原照片圆窗 |
| 配图、文章插图、知识图解、流程图 | 配图 | 按信息密度选择三档，不添加 Jacky 真人或头像 |

用户可以直接说“封面模式”或“配图模式”。明确用途时直接执行；只说“做图”且上下文无法判断时才问用途。封面用途优先于内容密度：文章有流程，不等于封面要画完整流程。

## 按需读取

共同读取 [视觉规范](references/style-dna.md) 和 [芽仔身份](references/yazai-ip.md)。

- 封面：读取 [封面制作](references/title-cover.md) 和 [场景隐喻](references/scene-metaphor.md)。封面规则覆盖场景隐喻中的“不加大标题”和配图角色尺寸限制。
- 配图：只读取对应的 [场景隐喻](references/scene-metaphor.md)、[知识图解](references/knowledge-diagram.md) 或 [信息可视化](references/information-visualization.md)，不同时加载三份。
- 制作后读取 [验收清单](references/qa-checklist.md)。

## 先理解文字，再设计画面

每次在内部形成一份简短视觉任务：

1. **核心判断**：读者最后应记住什么？保留原文的条件、范围、因果和不确定性，不能从关键词猜观点。
2. **关系**：这是冲突、转折、因果、组成、顺序还是数据比较？只选支撑本图的关系。
3. **文字层级**：哪些字必须逐字保留？封面的结论或转折通常做主标，背景与铺垫做较小、较轻的辅文；不机械放大前半句。
4. **视觉动作**：芽仔通过哪个动作影响哪个物件，使读者看懂判断？先建立动作与意义的关系，再选择道具和配角。
5. **删减**：拿掉哪个元素会损失理解，哪些只是装饰？封面只保留一个主场景、一项主要动作和至多三个辅助物件或标签。

写清“读者先读到什么，再从哪个动作理解什么”才生成。原题要求必须保留全文；允许断行和调整主次。需要压缩时只能压缩已知含义，不发明数字、结果、引用或承诺。

芽仔是理解内容的行动者，也是可识别的品牌 IP，不能缩成角落装饰。Bot、剪刀、电脑、笔记、对比句式均按本次内容决定，不能成为固定套件。遮住文字时，画面仍应保留关键关系。

## 配图的三档密度

- **场景隐喻**：一个观点、冲突或情绪；一个动作和紧凑物件组，0–3 个短标签。
- **知识图解**：解释“是什么、由什么组成、两者有何差别”；3–5 个概念、4–8 个短标签、一个主关系骨架。
- **信息可视化**：精确的步骤、时间、数量、因果、分支或依赖；先规划页数，每页通常 4–6 个模块和一个明确阅读路径。过载则拆页，不缩字硬塞。

精确顺序、数值或依赖优先进入信息可视化；无严格顺序的组成关系用知识图解；单个观点用场景隐喻。

## 画幅

- 配图：16:9、4:3、3:4；未指定且用途无法推断时默认 16:9。
- 小红书封面：3:4，最终 PNG 严格为 **1245×1660**；默认使用固定窗框模板。
- 公众号：2.35:1，建议 1410×600 或 900×383。
- X Article：5:2，建议 1500×600。
- 用户明确要公众号与 X 共用：1500×600，关键信息放在水平中央 94% 区域；要原生双版则分别构图。

横版封面延续自由构图与已确认旧头像，不拉伸或裁切小红书模板。用户指定的模板、素材和尺寸优先。

## 制作

- 先简述模式、比例和一句视觉任务。用户要求“生成、看效果、做图”后直接制作，不重复要求选模式。
- 内置图像生成工具负责变化的内容与插画。芽仔第一身份参考始终是 `assets/ip/yazai-paper-blue-anchor-v1.png`；纸纹只作为历史媒介参考，不能覆盖当前清洁底色要求。
- 配图用相应模式母版控制信息密度；固定模板封面用母版资产锁定背景，详见封面说明。
- 小红书封面采用 **固定底图 + 透明内容层 + 原人物层**。不得让生成模型重绘固定底图或真人，再靠提示词声称保持原样。通过 `scripts/compose-cover.py` 合成并核验。
- 原照片圆窗为默认人物层；用户提供并确认的透明人物抠像可替换。未提供抠像时不得制造人物；明确要求新抠像则另行处理原照片并核验脸部，合格后再合成。
- 正文配图不加载人物资产。旧头像只在相应自由构图封面使用，不与真人圆窗重复出现。
- 提示词顺序：核心关系 → 标题与布局 → 芽仔动作 → 人物避让 → 逐字文字 → 身份、清洁材质和避免项。文字每条出现一次，不临时增加说明。
- 全图只有一个主蓝色语义焦点；蓝色强调判断、关键词或关键动作，不能只作装饰。芽仔面罩保留单侧一块连续柔和反光，不添加眼睛或孤立亮点。
- 固定模板的内容层要真实透明；白色衣服、纸条等主体保持不透明。不能用全图去白或色键处理冒充透明层。

## 修订与保真

先列出所有问题，再决定修复范围。固定底图和人物层始终锁定；内容变化仅重做内容层，不把完整合成成品送回生成模型。

文字或单物件错误优先局部修改；结构错误才重做变化层。同一轮制作最多一次生成式整体返修；后续只剩孤立斑点时转局部处理，不能连续整图重绘。新增用户构图要求开启新修订，但仍从原始资产和正确的内容层出发。

工具无法生成真实透明内容时，明确报告并仅重试内容层；合成失败不能退回全图重绘。母版缺失、人物缺失或保护区碰撞都先解决，不用占位图交付。

## 交付

项目目录规则优先；在项目自己的输出版本中保存 `assets/<topic-slug>-yazai-visuals/`。顺序命名并保留旧版。

展示成品并提供本地文件链接、尺寸、用途。说明文字核验、尚未通过的检查、生成式返修和局部处理次数。区分生成原始分辨率、合成母版和发布尺寸，不把放大输出称为原生高清。小红书封面还须检查手机缩略图、IP 露出和人像清晰度。

## 边界

本 Skill 处理品牌封面与配图。真人主体大片、真实软件证据和 Oil Cover 信息层级进入 `$jacky-cover`；本模式中的原照片仅作品牌人物层。真实界面必须用真实截图，不虚构 UI、Logo、事实或成功状态。只发布用户明确要求发布的内容。
