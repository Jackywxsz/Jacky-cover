# Jacky 黑短袖姿势库

由 front / side 原照生成，**用户 2026-11-07 逐张认可**后入库。生成提示词见 `experiments/pose-library/pose-prompts.md`。
使用时每次只上传一张，并且必须同时上传 `../jacky-reference-front.jpg`。

| ID | 动作 | 适合场景类型 |
|---|---|---|
| J01 | 正面站立，双手自然下垂 | 通用；芽仔场景在身侧 |
| J02 | 侧身，单手前伸托掌，看向掌心 | A 托举小世界、E 对视交接 |
| J04 | 俯身，双手撑在前方，低头看左下 | B 巨人俯看 |
| J06 | 正面微笑，单手张掌朝左展示 | D 侧边引导、E 对视交接 |
| J07 | 双手捧在胸前，低头看手 | A 托举小世界（小而珍贵的东西） |
| J08 | 抱臂，看镜头 | 观点判断类，芽仔承担全部操作 |

缺口：举屏幕（J03）、指向（J05）首版用户认为不像本人，重做中；入库前 C 举屏幕类型暂用 J01 并在提示词里写持平板。
