# 固定纸蓝互动模板

当前只有 `interaction-profile.json` 指定的一套默认模板；v5调整布局与逐行字号，继续复用v4纸底和黑蒙版的相同字节。旧版规则已归档，不在本文保留第二组互斥默认。

## 固定视觉

- 背景以v4固定PNG为唯一视觉源：暖纸上部与中央、右上方较宽的柔和灰蓝过渡、左侧中下部的清蓝晕染。来自用户指定封面去除人物/贴纸/文字/黑遮罩后的背景还原；隐藏区域属补全，不宣称逐像素恢复。不得重新解释为左右蓝边框、纯白中心、小角落点缀或整块蓝紫底。固定PNG只缩放到模板尺寸一次，后续重复使用，不让生图重画。
- 已确认的暖纸底原版保存在assets/covers/masters/paper-blue-paper-master-v3.png，hash见配置；当前v4在同一设计基础上微调蓝色，减少紫感。原版是留存母版，不自动回退，不再重新发明纸底。
- 背景与遮罩分开。v4采用连续smoothstep曲线，从高度38%的0%黑alpha平缓过渡到94%高度的94%alpha，其余边界平缓连接。画面50/60/68/77/90%高度的alpha约11/32/52/73/92%；数值源是配置，报告记录实际采样。替代上一版在68–77%高度内从25%骤增到85%的陡坡，避免像单独铺黑条。脸部清晰，阴影覆盖场景下半部并连续穿过标题区。不要把纸底本身预先压黑。
- 层序：固定背景→透明互动前景（下缘平滑收口）→黑蒙版→小字和主标题。半身人物延伸到标题后，末端不能在主标题上方露出硬截线。不能将旧压平图再蒙一次黑；合成器不接受任意替换背景。
- 真人每轮从两张原照全新生成，不输入旧生成肖像，不在生成脸上反复编辑。皮肤清晰自然，无粉笔白斑、脏纹、压扁脸型。真人自然照片外沿，无描边。芽仔和道具保留纸片/贴纸的薄切边、手绘轮廓和浅接触阴影；局部材质不能污染真人皮肤或整张纸底。禁止光滑玩具、白棚家电、厚重块状3D阴影。
- 标题两行，严格保持用户指定断行；支持逐行字号，短第一行可单独放大，不能擅自挪词。真实阿里巴巴普惠体Bold，白字与一个橙色语义重点；按字体真实advance宽度排字，不能拉伸、加假粗或由模型近似。小字使用清楚自然的手写字体，随留白位置安排；不是第三个标题。

## 内容与动作

先确定一句核心判断、必须可识别的内容主体和一个关系，再设计人物与芽仔的动作和作用结果。具体产品/角色/团队参考优先于通用隐喻，不能用通用图标或芽仔替代原题主体。真人参与其中但不抢走语义中心。固定身份/媒介不等于固定姿势/道具；同一人物可自然前倾递交、展开、托举并操作、双侧比较、统筹协作或观看；先按内容设计关系，再读pose-library.md选动作，不能把指一下作为默认。一个主场景，至多三个辅助物件，遮字后仍能理解主要关系。

## 必须分开验收

1. **数值/图层**：母版hash与配置一致；真透明前景而非白底；白色衣服/纸片内部不透明；独立纯黑alpha蒙版；实际渐变曲线与采样值；最终尺寸；真实字体；文字/前景边界；只改文字时主体不变化。
2. **人物**：实际上传清单没有旧生成肖像；对照原始照片的脸型、五官、年龄与皮肤；两条手臂逐段可追踪；没有缺臂感、多指或错误连接；肩/袖不触边；蒙版没有掩盖结构错误。
3. **芽仔**：身份与原始比例不变，完整躯干、短腿圆靴，腿脚不拉长、躯干不挤没；无五官面罩单侧连续反光；仍是纸片/贴纸媒介；动作与物件有接触和结果；不能变成旁观装饰。
4. **语义**：画面传递原题要点，用户指定对象/产品/群体真实出现在画面且可识别；遮住芽仔仍能认出主要对象，未用通用生产线代替所有主题；没有虚构事实或产品能力。
5. **整体**：暖纸主底/右上与左侧蓝晕和固定参考母版一致，人物与主要内容上移、上半部没有无意义的大块空区；人物上部清晰，人物下缘融入标题暗部；小字克制且位置合理；手机缩略图中两行主标与互动关系可读。

任何视觉项不通过就记录具体缺口，不能以脚本pass覆盖人工fail。脚本报告默认是“待视觉审阅”，不会自动宣称完成。
