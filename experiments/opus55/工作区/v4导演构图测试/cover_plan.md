# 新版导演构图实测

核心：小任务交出→芽仔接管→一整套成果向观众递出，非体育竞赛。
第一落点：左前方大蓝色成果夹与一个相连的三折成果纸层；不再用小桌子承载缩小的成果。
动势：右上较小任务单→左中芽仔接力→左前景大成果，呈斜向/三角阅读。
空间：成果夹在前压住人物部分下胸；人物右侧中景；芽仔站在夹页折边上，用接卡与推成果建立因果。后景空白即固定纸蓝底。
身体：右臂胸前交小卡，左臂托成果远端。肩肘腕手完整，不能被纸层全遮；原照起稿无旧生成脸。人物视线进入场景，脸尽量近正面保身份。
画布：标题下1/3和蒙版沿v3；上半部关键成果在蒙版浅区；人物下缘自然延伸暗区。不把长腿/桌腿放进alpha边界迫使主物件缩小。
文字：告别写报告 / Opus 5.5接管比赛，后四字橙色，177/109px、38px字形间距。副标题一句指令，调研到演示，真实南安体46px，沿用上一版。
误读风险：只看出展示文件；若接任务与大成果的关联不清，语义检查不得判通过。无字图、全图、缩略图分别看，人物/芽仔身份、双臂、媒介与构图分别记录。最多一次原照重试。
